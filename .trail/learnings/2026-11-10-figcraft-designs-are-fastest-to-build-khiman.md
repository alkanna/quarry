## Decided
Design mockups for Quarry are generated by a small Python script that writes one SVG per frame, then imported into FigCraft with file.import. The import keeps text as real text layers (Inter and JetBrains Mono, tspans become styled runs), so the frames stay editable. Building the same frames node by node through create_node takes dozens of calls per frame.

## Watch out
- docs/sql/designs.figcraft may be open in the FigCraft app with unsaved edits; opening it from an agent reports dirty and stale. Do not save that tab over the file on disk; make a new file instead.
- After import, set the frame name, cornerRadius 10, clip and the drop shadow with node.set, to match the existing frames (page background #ECEAE6, title Inter Bold 22 #111111, note Inter 13 #555049, Workbench frame left and Paper frame 60 px to its right).
- Measure text widths from the embedded fonts (fontTools via `uv run --with fonttools`), since PIL is not installed.

In the code: docs/palette.figcraft (command palette designs A to E), palette colors from DARK_PAL and LIGHT_PAL in src/ui/theme.rs.
